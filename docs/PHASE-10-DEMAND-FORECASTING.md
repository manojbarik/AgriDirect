# Phase 10 — AI Demand Forecasting

This phase adds agricultural demand prediction. Because no real historical order/demand dataset exists yet, the model is trained on a **clearly labeled synthetic demo dataset** and all outputs are marked as demo predictions until real data is connected.

## Dataset

`ml/demand/data/synthetic_demand.csv` (4,000 rows), generated by `ml/demand/data.py` with a fixed seed and `is_synthetic = True`. Features:

- **Crop**: crop name, variety, category
- **Location**: state, district
- **Temporal**: season, month, holiday/event flag (festival months)
- **Market**: buyer type (WHOLESALER / BUSINESS / RESTAURANT / RETAILER / INDIVIDUAL), price, quantity sold, historical demand
- **Target**: `demand_kg` (monthly demand)

Demand is generated from realistic relationships (historical base × seasonality × event uplift × buyer-type modifier × price elasticity) plus noise.

## Models Compared

| Model | Validation MAE | Validation RMSE | Validation R² | Validation MAPE |
| --- | --- | --- | --- | --- |
| Historical Average Baseline | 499.7 | 694.2 | 0.480 | 43.67% |
| Random Forest | 134.6 | 203.6 | 0.955 | 9.10% |
| **LightGBM** | **114.4** | **173.7** | **0.967** | **7.55%** |
| XGBoost | 122.6 | 179.1 | 0.965 | 8.46% |

Selected best on validation RMSE: **LightGBM**. Top features: `historical_demand`, `price`, `quantity_sold`, `month`, `buyer_type` (WHOLESALER), holiday flag.

**Evaluate with:** MAE, RMSE, MAPE (all reported; MAPE via `mean_absolute_percentage_error`).

## API

`POST /api/v1/ai/demand-prediction`

Request example:
```json
{ "crop_name": "Tomato", "state": "Maharashtra", "month": 9, "buyer_type": "RETAILER", "price": "25" }
```

Response:
```json
{
  "crop_name": "Tomato",
  "state": "Maharashtra",
  "month": 9,
  "predicted_demand": 983.4,
  "unit": "kg",
  "forecast_period": "month",
  "predicted_demand_lower": 732.7,
  "predicted_demand_upper": 1234.1,
  "confidence_score": 0.97,
  "model_version": "v1.0.0-synthetic",
  "best_model_name": "LightGBM",
  "is_synthetic": true,
  "recommended_quantity": 983.4,
  "historical_demand": 1500.0,
  "disclaimer": "DEMO / SYNTHETIC MODEL: ..."
}
```

Uncertainty uses residual standard deviation (±1.96σ). `recommended_quantity` is aligned to predicted demand so farmers can size their supply to satisfy it.

## Farmer Dashboard Visualization

`DemandForecastWidget` (embedded in the farmer dashboard) presents the funnel:
